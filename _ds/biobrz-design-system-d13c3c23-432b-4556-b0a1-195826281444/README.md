# BIOBRZ Brand System

Sistema de identidade visual completo da BioBrz Consultores — boutique de consultoria tributária e auditoria independente.

## 📖 Sobre

Uma marca que não precisa ser explicada. Quinze anos construindo em silêncio.

## 🎯 Conteúdo

- **Logo** — 3 versões oficiais (colorida, branca, preta)
- **Paleta de Cores** — 5 cores institucionais
- **Tipografia** — Fonte Barlow (9 pesos)
- **Ícones** — 21 ícones SVG
- **Guidelines** — Guia completo de aplicação

## 🚀 Como usar

Abra o arquivo `index.html` em seu navegador para visualizar o sistema completo e baixar os ativos.

## 📦 Downloads disponíveis

1. **Logotipos** — PNG em alta resolução
2. **Ícones SVG** — 21 ícones vetoriais
3. **Tipografia** — Fonte Barlow (18 arquivos TTF)
4. **Kit Completo** — Todos os ativos em um único arquivo

## 📂 Estrutura

```
BIOBRZ-Brand-System/
├── index.html              # Página principal
├── brand-site.js           # Script interativo
├── styles.css              # Estilos globais
├── assets/
│   └── logos/              # Logotipos (PNG)
├── icons/                  # Ícones SVG
├── fonts/                  # Fonte Barlow (TTF)
├── logos/                  # Logotipos vetoriais (PDF)
└── README.md
```

## 🎨 Características

- Identidade visual sofisticada e moderna
- Sistema de cores baseado na bandeira brasileira
- Tipografia geométrica (Barlow)
- Ícones consistentes e escaláveis
- Documentação completa

## 📋 Especificações

- **Cores**: 5 cores principais + neutros
- **Tipografia**: Barlow (100-900 weight)
- **Ícones**: 24×24, stroke 2px, cantos retos
- **Formatos**: PNG, PDF, SVG, TTF
